# 01 · 安装与卸载
English: `docs/01-安装.en.md`

## 你需要什么

| 项 | 要求 |
|---|---|
| Minecraft | 1.21.5 – 26.3（分两份变体，见 [04-兼容与版本](04-兼容与版本.md) 的映射表） |
| 装什么 | 一份 zip：1.21.5–26.2 用 [`../dist/doom.virtual.health-v3.1.1.zip`](../dist/doom.virtual.health-v3.1.1.zip)；26.3 用 [`../dist/doom.virtual.health-v3.1.1-mc26.3.zip`](../dist/doom.virtual.health-v3.1.1-mc26.3.zip) |
| 要不要开实验性玩法 | 不用 |
| 有没有前置依赖 | 没有。零 Mod、零外部数据包、零资源包 |
| 单人还是服务器 | 都行，服务器要能装数据包（原版 / Fabric / Paper 都行） |

> 包里的两个命名空间 `doom.virtual.health`（核心）与 `doom.bossbar`（血条联动）在同一个 zip 里，
> 一起装一起生效；只用核心、不要血条也能玩（不调用 `doom.bossbar:*` 就行）。

## 装（单人存档）

1. 下载对应你 MC 版本的那份 zip（1.21.5–26.2 → `v3.1.1`；26.3 → `v3.1.1-mc26.3`），先对一下校验值（见下）；
2. 解压 → 得到一个文件夹 `doom.virtual.health/`；
3. 把它整个放进存档的 `datapacks/`：

   ```
   .minecraft/saves/<你的存档>/datapacks/doom.virtual.health/pack.mcmeta   ← 必须是这个深度
   ```

   **多套一层就不加载**（例如 `datapacks/doom.virtual.health/doom.virtual.health/` 是错的）；
4. 进游戏（或已经在游戏里就 `/reload`）。

## 装（服务器）

1. 把解压出来的 `doom.virtual.health/` 放进 `<服务端根目录>/world/datapacks/`（多世界服务端放对应世界的 `datapacks/`）；
2. 控制台 `/reload` 或重开服；
3. 路径同样是 `.../world/datapacks/doom.virtual.health/pack.mcmeta`。

> 顺便说一句：这个包不碰原版房规（不改 `gamerule`、不动刷怪、不改原版血量上限），
> 它只对自己“注册过”的实体起作用。所以装在有别的数据包的服务器上一般不会打架。

## 怎么确认装上了

按顺序做这三步，任一步对了就说明它在跑：

1. `/reload` 之后全体玩家会在聊天栏看到一句红色的：

   ```
   [DVH] Virtual Health System Loaded.
   ```

   （来自 `doom.virtual.health:__load__`；同时 `doom.bossbar:__load__` 也会挂上）
2. 敲 `/function doom.virtual.health:__help__`，聊天栏会打印一整页 API 清单（只给执行者看）。
3. 召唤一只有虚拟血量的怪，它脚下会出现一条血条：

   ```
   /summon minecraft:zombie ~ ~ ~ {data:{dvh:{max_health:40d, health:40d, on_death:"say died"}}, NoAI:1b}
   ```

     血条出现 = `auto_init` + `doom.bossbar` 两条链路都通了。

数据包挂了的话，加载期会在 `logs/latest.log` 里留下 `Failed to load function ...` 或
`Couldn't load ... as it's not a valid pack` 之类的行。拿这两句去搜，基本能定位到是哪一步错了。

## 卸载

1. 先把虚拟血量实体摘干净（直接删包会让系统停在不一致的状态：实体身上还挂着
   `virtual_health_entity` 标签、血条还挂在那儿）：

   ```
   /function doom.virtual.health:__unload__
   ```

   它会遍历所有 `@e[tag=virtual_health_entity]`，调用 `api/remove {with:{kill:false}}`（不杀实体），并清理血条与计分板。

2. 删掉 `datapacks/doom.virtual.health/`；
3. `/reload`。

`storage doom.vh:ctx` / `doom.vh:const` / `doom.dbb:ctx` 里剩下的常量数据留着无害；想彻底清干净可以
`/data remove storage doom.vh:ctx ...` 逐个删，或者干脆不管它，重装会覆盖。

## 校验下载的文件

`../dist/SHA256SUMS.txt` 里是 zip 的 sha256，在 zip 所在目录跑：

```
Linux / macOS:        sha256sum -c SHA256SUMS.txt
Windows PowerShell:   (Get-FileHash .\doom.virtual.health-v3.1.1.zip -Algorithm SHA256).Hash
```

输出 `OK`（或哈希与表里那串相等）就是完整下载；不等就别用，重新下。

## 装不上时的排查顺序

| 现象 | 先查这个 |
|---|---|
| 聊天栏没有 `[DVH] ... Loaded.` | 路径深度对不对（`datapacks/doom.virtual.health/pack.mcmeta`）；有没有 `/reload` |
| 日志说版本不符 / 包无效 | 游戏版本是不是低于 1.21.6（`pack_format` < 48）；zip 是不是解压了、还是直接把 zip 丢进去了（必须解压） |
| 怪脚下没有血条 | 是不是 `doom.bossbar` 命名空间没加载（重装整包）；`visible` 选择器是不是把你看漏了 |
| 打了不掉血 | 那只实体是不是虚拟血量实体（`/tag <实体> list` 看有没有 `virtual_health_entity`）；是不是被 `set_invulnerable {state:1b}` 设成无敌了 |
| 改了 `vitality.json` 没生效 | 那个文件要**重启服务器**，`/reload` 不读它 |
