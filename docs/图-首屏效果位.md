# README 首屏效果位（占位说明）
English: `docs/图-首屏效果位.en.md`

README 第一屏留了一个图片位，但现在还没放图。在那之前保持注释状态，不要留半张破图。

## 要拍什么

一张能同时说明“这是什么”和“它在跑”的截图。建议这样：

1. 进一个 1.21.5 – 26.3 的世界（按映射表选对应变体），装上 `doom.virtual.health/`，`/reload`；
2. 召唤一只有虚拟血量的怪（血量写成原版绝不可能出现的数，一眼能看出不是原版血量）：

   ```
   /summon minecraft:zombie ~ ~ ~ {data:{dvh:{max_health:40d, health:40d, on_death:"say died"}}, NoAI:1b}
   ```

3. 等它脚下出现血条，打它两下（血条要动，但没死），这时按 F2。截图里要同时看到怪和血条。

## 拍完怎么放

1. 存成 `docs/assets/首屏效果.png`（建议宽 1280–1600，透明边裁掉）；
2. 打开仓库根的 `README.md`，把这一行的注释去掉：

   ```html
   <p align="center"><img src="docs/assets/首屏效果.png" width="720" alt="doom.virtual.health 在存档里跑起来的样子"></p>
   ```

3. 顺手把上面那段“拍什么”的步骤删掉。

## 约束

- 截图里不要出现：服务器 IP、玩家 UUID、真实玩家名、聊天记录里的私人内容；
- 不要放 GIF（仓库不带大二进制）；短视频请放 Release 的正文里，不要进仓库；
- 图别超过 1 MB，放 `docs/assets/` 下，和手册一起进库。
